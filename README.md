## Project overview
A responsive frontend study planner built with HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Chart.js and browser LocalStorage. This final package integrates the work from Modules 1–4 and adds final accessibility, validation, responsive and documentation refinements.

## Features included
- Subject management: add, view, edit and delete subjects.
- Study task management: create tasks, assign subjects, set deadlines, change status, edit and delete tasks.
- Dashboard metrics for total, completed and pending tasks.
- Subject-wise progress and interactive charts.
- Smart priority recommendations based on pending workload and urgency.
- Task search, status/subject filters, and upcoming deadline list.
- Browser LocalStorage persistence (data remains in the same browser profile).
- Responsive Bootstrap layout for desktop, tablet and mobile widths.
- Form required-field validation, explicit form labels, keyboard-visible focus, skip link and reduced-motion support.
- Confirmation before destructive subject/task deletion and cleanup of tasks linked to a deleted subject.

## Technologies
HTML5, CSS3, JavaScript ES6+, Bootstrap 5, Chart.js, LocalStorage, Git/GitHub, VS Code.

## Run locally
1. Extract the ZIP archive.
2. Open the extracted folder in VS Code.
3. Open `index.html` with the Live Server extension, or double-click it to open in a browser.
4. An internet connection is required for the Bootstrap and Chart.js CDN libraries.

## Deploy with GitHub Pages
1. Create/open your project repository on GitHub.
2. Upload the contents of this folder (not the ZIP itself): `index.html`, `css/`, `js/`, `README.md`, and documentation files.
3. Open **Settings → Pages** in the repository.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the generated URL. Test that URL before submitting it.

## Data and privacy note
This is a frontend-only project. Subjects and tasks are stored in the browser's LocalStorage; they are not synced between devices and clearing browser data can remove them. Bootstrap and Chart.js are loaded from CDNs.
